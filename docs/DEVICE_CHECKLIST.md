# 実機確認チェックリスト（ステップ2）

**目的**：次の2点を、実機で確かめることです。

- 無改造の KoPlay が Kindle で動くか
- 給電・スリープ・USB・SSH が実際にどう振る舞うか

ここで分かった事実をもとに、3-1 以降（タブ、給電の制御など）を設計します。

**かかる時間**：全部で1〜2時間ほどです（放置して待つ時間を含みます）。順番どおりでなくてもかまいません。

**結果の返し方**：最後の「結果の記入欄」を埋めて返信してください。あわせて、診断のファイルを2つ送ってください（[結果の返し方](#結果の返し方)）。

**診断画面の使い方**
- 「更新」：最新の状態を表示し直します。
- 「レポート保存」：今の内容をファイルに保存します。
- 「記録を消去」：記録（イベントのログ）を空にします。
- 「閉じる」：画面を閉じます。

診断を閉じていても、記録は裏で取り続けます。記録するのは、充電の開始と終了、スリープとその復帰、Wi-Fi の接続と切断です。

### SSH の手順（Windows の PowerShell を使う）

Windows 10/11 には `ssh` と `scp` のコマンドが最初から入っています。

1. Kindle：Wi-Fi をオンにし、メニュー → ⚙（設定）のタブ → ネットワーク → **SSH server** を開く。
2. Kindle：**Login without password (DANGEROUS)** をオンにする。
   - パスワードなしでログインできる設定です。確認が終わったら、必ず手順 7 で戻してください。
3. Kindle：同じ画面の一番上の **SSH server** をタップしてチェックを入れる（これで起動します）。「SSH server started.」と出るので、表示された IP アドレス（例：`192.168.1.23`）とポート（`2222`）を控える。
4. PC：PowerShell を開き、次を入力する（IP は手順3のもの）。
   ```
   ssh -p 2222 root@192.168.1.23
   ```
   - 初回は「Are you sure you want to continue connecting?」と出るので、`yes` と入力する。
   - パスワードを聞かれたら、何も入れずに Enter を押す。
5. PC：つながったら `ls /mnt/us/koreader` と入力し、`plugins` や `settings` が表示されることを確かめる。`exit` で抜ける。
6. PC：ファイルを1つ送ってみる。例として、このリポジトリの `README.ja.md` を送る（`scp` のポート指定は**大文字**の `-P` です）。
   ```
   scp -P 2222 .\README.ja.md root@192.168.1.23:/mnt/us/
   ```
   Kindle の USB ドライブのいちばん上に `README.ja.md` ができていれば成功です。確認後は削除してください。
7. Kindle：一番上の **SSH server** をもう一度タップしてチェックを外し（停止）、**Login without password** をオフに戻す。

うまくいけば、今後のコピーは USB ケーブルを使わずに SSH でもできます。安全な公開鍵の方式は、必要になったときに手順を用意します。
